# Palindrome Number in Java

##  Description
This Java program checks whether a given number is a palindrome. A palindrome number reads the same forward and backward, such as 121, 131, and  madam (for words).

##  Technologies Used
- Java
- Scanner Class
- Loops and Conditional Statements

##  How It Works
1. The user enters a number.
2. The program reverses the number using a `while` loop.
3. It compares the reversed number with the original number.
4. If both are equal, it displays **Palindrome Number**; otherwise, it displays **Not a Palindrome Number**.

##  Sample Output

```text
Enter a number: 121
Palindrome Number
```

```text
Enter a number: 123
Not a Palindrome Number
```

##  How to Run
1. Save the code as `PalindromeNumber.java`.
2. Open a terminal in the file's directory.
3. Compile the program:

```bash
javac PalindromeNumber.java
```

4. Run the program:

```bash
java PalindromeNumber
```
